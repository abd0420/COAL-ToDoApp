# COAL ToDoApp 📝

A simple To-Do List application built as a semester project.

## Features

* Add, view, and manage daily tasks efficiently.

* Lightweight and implemented using low-level architecture/assembly concepts.

## Prerequisites

* **Visual Studio** (with the necessary C/C++ or assembly development workloads installed, depending on your project's configuration).

## How to Run the Program

1. **Clone the Repository:**

   ```
   git clone https://github.com/abd0420/COAL-ToDoApp.git
   
   ```

2. **Open in Visual Studio:**

   * Launch **Visual Studio**.

   * Select **Open a project or solution** and navigate to the cloned `COAL-ToDoApp` folder.

   * Open the solution file (`.slnx`) or project file.

3. **Build and Run:**

   * Press `Ctrl + Shift + B` (or go to **Build > Build Solution**) to compile the project.

   * Press `F5` (or click the **Local Windows Debugger** button) to run the application.
